How ARK works.

Overview

ARK is a launchpad on top of pump.fun. A coin launched here is an ordinary pump.fun coin created with two settings fixed for good: it is paired to $ARK, or to another pump.fun coin you choose, and it is a holder-reward coin, so 100% of its creator fees go to the people holding it.

ARK never holds keys or funds. The server builds each transaction with pump.fun's official SDK, simulates it on-chain, and your wallet signs it.

Launch flow

  1. Your picture and metadata go to pump.fun's IPFS endpoint, the same one pump.fun's own site uses.
  2. ARK builds the create transaction (create_v2) with the pair and holder rewards set, plus a memo and the ARK registry tag, and simulates it.
  3. You sign. If the address search found a key ending in "ark", your browser adds that signature for the new mint.
  4. If you chose a dev buy, a second transaction swaps SOL → pair → your coin through pump.fun's multi-hop swap, capped at 1 SOL.
  5. The coin shows up on the board as soon as the registry sees it.

Pairs

$ARK is the main pair. Any other pump.fun coin can be a pair when all of these hold, checked on-chain at the moment you launch:

  • it is itself paired to SOL (pump.fun allows 1 level of pairing),
  • it is not a mayhem-mode coin,
  • it is still on its bonding curve, or it graduated into a PumpSwap pool, so SOL can be routed through it.

Coins that left pump.fun for Raydium before PumpSwap existed have no pump.fun pool to route through, so they can't be a pair.

Holder rewards

Because the creator of every ARK coin is its holder-rewards account, creator fees build up there instead of in a wallet. pump.fun collects them and pays them out to the coin's holders, in the pair coin. Each coin page shows what is waiting and what has been paid, read from the chain.

Gangway rules

  • Two coins per ticker at most (2).
  • Up to 50 launches per wallet per day.
  • Dev buy up to 1 SOL.
  • No major tickers, and no ticker already worth $1M+ on Solana.
  • A real picture: PNG, JPG, GIF or WEBP, not a copy of a coin already aboard.
  • Links checked for format, and the website has to load.
  • Descriptions that promise returns get flagged.

Verify a coin

  1. Open the coin's page on ARK: the "Verified on-chain" list re-reads its bonding curve every few seconds.
  2. Or check it yourself: the bonding curve's quote_mint is the pair and is_holder_reward is true.
  3. Its create transaction contains the memo ark:v1:<TICKER> and the registry account.

Public API

Read-only endpoints, no key needed:

GET /api/config        settings + pump.fun switches + fees
GET /api/ark           $ARK price, market cap, curve, pairable
GET /api/pairs         $ARK + real pump.fun coins that can be a pair now
GET /api/pair?m=MINT   can this coin be a pair?
GET /api/coins         every coin launched through ARK
GET /api/coin?m=MINT   one coin: curve, checks, rewards, holders, trades
GET /api/live          pump.fun right now

Good to know

  • Pairing is final: a coin stays paired to the coin it launched with.
  • The dev buy is its own transaction, sent right after the create.
  • pump.fun sets the minimum holding for holder rewards and the payout timing.
  • Buying a coin with SOL goes through its pair in the same transaction, so price moves in the pair affect the route.
